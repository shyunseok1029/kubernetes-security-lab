# Argo CD와 GitOps 개인 실습

## 목적과 개념

개인 환경에서 Argo CD를 설치하고 공개 예제 애플리케이션을 이용해 GitOps 동기화 흐름을 살펴봤습니다. GitOps에서는 Git에 기록된 원하는 상태를 기준으로 배포 상태를 관리하며, Argo CD는 대상 클러스터의 실제 상태를 비교하고 동기화를 지원합니다.

## 수행 내용과 확인 결과

기존 개인 실습 PDF와 결과 이미지에 대한 조사 기록에서 확인한 범위입니다.

1. Argo CD 구성 요소를 설치·실행하고 CLI로 로그인했습니다.
2. 공개 `guestbook` 예제를 사용하는 Application을 생성했습니다.
3. Manual Sync 이후 `Synced / Healthy` 상태를 확인했습니다.
4. 재동기화 후 최종 상태가 복구된 기록을 확인했습니다.

이 기록은 수동 동기화와 최종 상태 확인에 관한 것입니다. 최초 `OutOfSync / Missing`과 Drift의 중간 상태는 독립 캡처가 부족하므로, 변화의 원인이나 중간 단계를 확정적인 결과로 표현하지 않습니다. 자동 동기화나 운영 환경 적용도 주장하지 않습니다.

## 근거와 한계

기존 조사에는 개인 실습 PDF와 결과 PNG가 근거로 정리되어 있습니다. 원본 이미지에는 환경 식별 정보가 포함될 수 있어 공개 전 권리와 민감정보를 확인해야 합니다. 이번 문서 작성 중 Argo CD나 클러스터를 다시 실행하지 않았습니다.
