# VMware 멀티노드 Kubernetes 개인 실습

## 목적과 구성

VMware 기반 개인 가상 환경에서 Kubernetes 클러스터의 구성 요소와 노드 상태를 학습했습니다. 기존 개인 실습 기록에는 Control Plane 1대와 Worker 2대, 컨테이너 런타임 containerd, 클러스터 구성 도구 kubeadm, 네트워크 구성 요소 Calico가 연결되어 있습니다.

## 수행 내용

- 개인 가상 환경에서 Control Plane과 Worker로 역할을 구분했습니다.
- containerd와 kubeadm을 이용하는 멀티노드 클러스터 구성 과정을 실습했습니다.
- Calico를 네트워크 구성 요소로 사용하고 노드와 시스템 Pod 상태를 확인했습니다.

일반적으로 kubeadm은 클러스터 초기화와 노드 참여를 돕고, containerd는 컨테이너 런타임 역할을 합니다. Calico는 Kubernetes 네트워킹을 제공하는 구성 요소입니다. 이 설명은 각 기능의 일반적인 역할이며, 별도의 네트워크 정책이나 처리량 검증 결과를 뜻하지 않습니다.

## 확인 결과와 한계

기존 조사 기록은 개인 저장소의 문서·커밋과 결과 캡처를 연결해 Node `Ready` 및 시스템 Pod `Running` 상태를 확인합니다. 이는 당시 확인된 상태에 관한 기록이며 지속적인 운영 안정성이나 모든 네트워크 경로의 정상 동작을 증명하지는 않습니다.

버전, 구체적인 설정값, 오류 해결 과정과 검증 시점은 이 문서에서 특정하지 않았습니다. 원본 이미지와 설정의 공개 권한 및 민감정보는 게시 전에 별도로 확인해야 합니다. 이번 문서 작성 중 환경을 다시 실행하지 않았습니다.
